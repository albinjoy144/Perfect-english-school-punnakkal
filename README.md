# Perfect English School, Punnakkal 🏫

Official modern responsive website for **Perfect English School, Punnakkal**, an early-childhood learning haven in Kerala dedicated to **Play School, Lower Kindergarten (LKG), and Upper Kindergarten (UKG)**.

---

## 🌟 Key Highlights & Features

- **School Branding & Palette**: Incorporates the official circular gold-and-maroon school emblem with glowing golden borders, modern typography (`Outfit`, `Fredoka`, `Plus Jakarta Sans`), and cheerful early-learning aesthetics.
- **Multi-Page Structure**:
  - `index.html`: Dynamic landing page with hero stats, curriculum cards, facility gallery, daily schedule timeline, parent testimonials, and FAQ accordion.
  - `about.html`: Heritage story of the diya (sacred lamp of knowledge) emblem, vision, mission, core values, and Montessori & Jolly Phonics pedagogy.
  - `programs.html`: Age-wise breakdown of Play School (2–3 yrs), LKG (3–4 yrs), UKG (4–5+ yrs), plus co-curricular puppet theatre, arts, and physical gym.
  - `contact.html`: Contact cards, visiting hours, interactive campus visit booking form, transport routes, and embedded Google Maps location.
- **Interactive Capabilities**:
  - Global Admission Enquiry popup modal accessible from all pages.
  - Floating WhatsApp chat button and direct phone call trigger.
  - Mobile slide-in drawer navigation with animated hamburger toggle.
  - Responsive design optimized for desktops, laptops, tablets, and phones.

---

## 💻 Tech Stack
- **HTML5**: Semantic markup, OpenGraph & SEO tags.
- **Vanilla CSS3**: Custom properties, glassmorphism, flexbox/grid, and micro-animations without external framework overhead.
- **Modern JavaScript**: Zero-dependency DOM handlers, accessible modal management, accordion toggles, and form submission feedback.
- **Node.js**: Built-in lightweight static development server (`server.js`).

---

## 🚀 Running Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/albinjoy144/Perfect-english-school-punnakkal.git
   cd Perfect-english-school-punnakkal
   ```

2. Start the local server:
   ```bash
   node server.js
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your web browser.
